# Student Dashboard
İNGİLİZCE
A dark-mode student tracker for courses, grades, weighted GPA (OBP), exam countdowns, and daily study goals. All data is saved locally in your browser (`LocalStorage`) and can be reset in one click.

## ⚠️ Important: How to Run Properly (ZIP Download)
1. Click **Code** > **Download ZIP**.
2. **Extract All** files from the ZIP archive into a normal folder first (do **not** open `index.html` directly inside the compressed ZIP window, or styles/scripts will not load properly).
3. Open the extracted folder and double-click `index.html`.

TÜRKÇE
## ⚠️ Önemli: ZIP İndirince Nasıl Çalıştırılır?
1. **Code** > **Download ZIP** ile dosyayı indir.
2. ZIP dosyasına sağ tıklayıp **Tümünü Ayıkla (Extract All)** diyerek normal bir klasöre çıkar (`index.html` dosyasını sıkıştırılmış ZIP penceresinin içinden doğrudan açma, yoksa tasarım/kodlar düzgün yüklenmez).
3. Çıkan klasöre girip `index.html` dosyasına çift tıkla.
